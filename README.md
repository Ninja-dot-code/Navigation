# Navigation Bar Practice

A responsive navigation bar practice project built with HTML, CSS, and JavaScript.

---

## About the Project

This repository focuses on building a clean and functional navigation bar, including mobile hamburger menu behavior.

### Features
- Responsive navigation
- Hamburger menu for mobile
- Smooth interactions
- Clean and minimal design

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
